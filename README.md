# 🧰 KratosKit

> "When the tools do the heavy lifting, you're free to do the creative thinking."

## 🧙‍♂️ What is this sorcery?

KratosKit is a collection of meticulously crafted bash scripts that turn tedious tasks into one-liners. Named after the God of War (because these scripts will fight your battles for you), this toolkit is designed for those who value their time and sanity.

## 👻 Requirements

- Bash (because we're old school like that)
- FFmpeg (for the animation tools)
- Ghostscript (for the PDF tools)
- A sense of humor (not strictly required, but highly recommended)
## ✨ Features That Actually Work 
- **📄 PDF A4-inator** - Tames wild PDFs into perfect A4 format faster than you can say "why is my printer freaking out again?" Your documents will be so professionally sized, people might think you actually know what you're doing.

- **🎬 aPNG Hypnotizer** - Turns boring videos into mesmerizing animated PNGs with customizable FPS. Ideal for showcasing that moment your cat realized it wasn't the alpha in the house anymore. Loop-ability: Infinite. Entertainment value: Priceless.

- **🔮 Coming Attractions** - Secret scripts currently incubating in our lab. They're like ninjas – deadly effective and you won't see them coming. Stay tuned unless you enjoy doing things the hard way.

## ⚡ Installation
```bash
# Clone this repo
git clone https://github.com/elyziumayo/Kratoskit.git

# Navigate to the directory
cd Kratoskit

# Make the master script executable
chmod +x master.sh

# Run the master script
./master.sh
```
